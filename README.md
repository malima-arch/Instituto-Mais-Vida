# Instituto Mais Vida

## Apresentação do projeto

O Instituto Mais Vida é um projeto acadêmico de desenvolvimento web criado para uma organização social. O site tem como objetivo apresentar os projetos da instituição, incentivar a participação de voluntários e facilitar o acesso às informações sobre doações e ações sociais.

O projeto foi desenvolvido com foco em acessibilidade, responsividade e interatividade.

## Tecnologias utilizadas

- HTML5: estrutura semântica das páginas.
- CSS3: estilização e organização visual.
- CSS Grid: criação do layout responsivo.
- Flexbox: alinhamento e organização dos elementos.
- JavaScript: interatividade, navegação, validações e manipulação dos elementos.
- Git e GitHub: controle de versão e gerenciamento do projeto.

## Como executar

Para executar o projeto localmente, clone o repositório do GitHub, abra a pasta no VS Code e utilize o Live Server para abrir o arquivo index.html no navegador.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão. Foram utilizadas branches para organizar as alterações, commits descritivos para registrar as mudanças e pull requests para integrar as alterações ao projeto.
